# Personas de donos de clínica no Brasil

Entrega principal deste repositório:

**[`personas-donos-de-clinica.md`](./personas-donos-de-clinica.md)** — 16 personas profundas de donos de clínica (dentistas, médicos, fisioterapeutas, psicólogos, biomédicos esteticistas, nutricionistas e veterinários), com recortes cruzados de gênero e modelo societário, padrões transversais e implicações para copy de marketing digital de atração + conversão + CRM.

## Auditoria

Pasta [`pesquisa/`](./pesquisa/) preserva as **notas brutas com fontes** que sustentam o documento principal — ~800 URLs reais consultadas em 7 frentes paralelas:

- `01-dentistas.md` — dentistas donos de clínica
- `02-medicos.md` — médicos donos de clínica/consultório
- `03-fisioterapeutas.md` — fisioterapeutas donos de clínica
- `04-outros.md` — psicólogos, biomédicos esteticistas, nutricionistas e veterinários
- `05-estilo-de-vida.md` — comida, viagem, carro, hobby, religião, política, mídia, consumo
- `06-genero.md` — diferenças reais homem × mulher por profissão
- `07-sociedade.md` — sociedade entre sócios, casal, investidor não-clínico, dissolução

Qualquer afirmação no documento principal pode ser rastreada até pelo menos uma URL nos arquivos da pesquisa.
